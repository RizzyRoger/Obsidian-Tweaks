## Why?

Extra

So, it rollovers adding more onto what I have. It does not not put yesterdays todos into todays categories.
## Features:
Whenever it becomes the day of the note that is in question, yesterdays note gets rolled over into the corresponding caterogry.
A caterory is identified as
- [ ] catergory name
	- [ ] task a
	- [ ] task b
	- [ ] task c
The tool should identify a caterogry from the previous day, for each category in there.
If any catergory has a corresponding catergory in the next day, it should rollover to that catergory.
If there are no catergories to rollover, it should just rollover to the bottom of the note.
